# 镜序 0.7.1

构建 32，macOS 14+、Apple Silicon。

## 调色时连续切图

- 修正调色模式下方向键必须聚焦照片画布才能切图的限制；文本框与滑块仍保留各自的方向键输入行为。
- 使用上一张、下一张或胶片栏切图后保持调色模式，载入目标照片自己的调整。
- 切图前等待当前调整保存；保存或目标会话载入失败时保留当前照片与编辑会话。到达范围边界保持当前会话，重复点击当前胶片不退出调色。

## 按住对比原图

- 按住按钮查看未调色、未裁剪的原图，松开、移出按钮或窗口失焦后恢复成片；切图或关闭会话也会结束对比。
- 松开立即恢复按下前的成片预览，再更新最新渲染；快速按下与松开会隔离过期原图渲染结果。
- 对比仅影响预览，不修改调色参数、保存修订或撤销历史；原照片保持不变。

## 验证与安装边界

本版本沿用 ad-hoc 签名、未经 Apple 公证的测试预发布通道。安装前结束后台任务、退出旧应用并备份图库，保留系统安全保护。发布流水线对发布提交执行 Debug／Release 构建、完整回归、应用签名、DMG 完整性与 GitHub 资产摘要校验。

上述功能在升级版本号前通过统一构建与完整回归，并完成本地测试包生成、签名与安装包校验、备份后替换及图库启动检查。新增回归覆盖松开立即恢复成片、快速对比切换、修订不变、修改参数结束对比及会话退出后忽略迟到手势。

调色界面的原生自动化连接曾中断，实际鼠标按住、移出、窗口失焦和调色连续切图尚未完成界面验收。下载后 Gatekeeper 首次安装与实际 Homebrew 升级亦未验收；Core 回归不替代这些检查。
