# 镜序 0.10.0 测试版

构建 38，macOS 14+、Apple Silicon。

## 专业暗房工作台与统一交互

- **统一三栏工作台**：本地图库与系统照片收拢为同一三栏壳层（左侧导览栏、中央暗房舞台、右侧按需展开的信息／质量或调色栏）；40pt 紧凑顶栏集中 `网格 G / 单图 ␣ / 对比 C / 调色 D` 舞台切换、内联「含子目录」范围胶囊、搜索筛选、画幅视图选项与右上角任务状态胶囊。
- **零色偏暗房画布与外观切换**：默认采用零色偏深色暗房界面，支持在设置中切换「跟随系统（看图与调色保持暗房）」；单图、双图同步对比、调色与构图裁剪画布统一使用 `#141416` 中性暗灰底色。
- **双画幅网格与零跳动悬浮操作坞**：默认「原画幅完整显示」不裁切照片构图，支持一键切换「1:1 方格紧凑」；悬停照片左上角直接勾选，底部悬浮毛玻璃胶囊操作坞集中提供评分、淘汰、对比、调色、导出、相册、关键词与更多操作，不再挤压顶部网格。
- **精密调色栏与单键快捷键**：进入调色（`D`）自动收起左侧导览栏，退出时恢复此前侧栏状态；296pt 调色栏顶部常驻 96pt 成片直方图，平铺「明暗影调 / 白平衡 / 色彩」4pt 双极性滑块（零点双向填充、双击归零、等宽数值胶囊输入），并支持按住键盘 `\` 实时对比原图。
- **统一安全清单确认与新版图标**：导入、归档、批量移动、废纸篓清理、失效索引清理、导出与系统照片写入统一采用固定清单预检确认弹窗；换装符合 Apple HIG 超椭圆规范的新版暗房光学应用图标。

## 验证与安装边界

本地统一入口已完成 arm64 Debug／Release 构建、30 项发布脚本检查、59 项 Release `JingXuChecks` 回归（含新增暗房工作台状态、滑块几何、单键路由、`#141416` 画布与超过 2,500 项完整范围选择检查）及 `JINGXU_UI_TEST_ROOT` 隔离启动核验。细节见 [界面重构记录](InterfaceRefactor.md)。最终发布提交由 GitHub Actions 再次执行构建、签名和资产摘要核对。

本包使用 ad-hoc 签名，未经 Apple 公证，以测试预发布版提供。安装前请结束后台任务、退出旧应用并备份图库。真实 PhotoKit 授权、iCloud 跨设备同步、真实相机 RAW、辅助功能受限外的完整桌面物理按键手感、Gatekeeper 首次下载安装与实际 Homebrew 升级仍待专用环境验收。若系统拒绝启动，不要关闭系统安全保护。
