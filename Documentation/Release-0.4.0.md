# 镜序 0.4.0

新增 Codex 调色连接：AI 助手可以读取镜序当前选择的真实预览，调整并保存照片参数，使用预设，以及在确认清单后批量调色或导出成片。单张操作同步镜序画面并支持撤销，原照片内容保持不变。

本版为 ad-hoc 签名、未经 Apple 公证的预发布版。macOS 14+、Apple Silicon；构建 19。安装包为 `JingXu-0.4.0-test.19-macOS-arm64.dmg`，发布后同步 Homebrew Cask。

## 使用 Codex 调色

- 设置中新增「允许 AI 助手连接」，默认关闭。启用后复制连接配置到同机 Codex；镜序需保持打开。连接说明和配套 Skill 见 [Codex 调色文档](https://github.com/beihai0xff/JingXu/blob/v0.4.0/Documentation/CodexColorControl.md)。
- 支持读取当前照片与明确选择的范围、最长边 2,048px 的渲染预览和直方图。单张曝光、明暗、白平衡、饱和度与鲜艳度修改自动保存，一次提交对应一步撤销。
- RAW 保留绝对色温，普通图片使用相对色温。预览与导出共用镜序渲染器，不使用生成式图片替换原片。
- 批量和导出先冻结照片、修订、参数与目标清单，用户确认后执行；返回任务进度，支持取消和批量撤销。新导出目录由镜序弹出系统选择器授权，导出不覆盖已有文件。
- 手动修改、切图、重新扫描后的文件身份变化会使旧请求失效。不同连接隔离清单，应用重启后旧清单失效，不自动重放。

## 连接与隐私

保留 App Sandbox，仅监听本机 `127.0.0.1`；校验连接密钥、Host 与 Origin。随机密钥保存于 Keychain，可在设置中重置，关闭连接即停止监听。

分析和渲染在本机完成；交给 Codex 的预览、文件名及参数会进入模型上下文。预览不携带原照片 EXIF／GPS；成片沿用现有元数据保留规则。

## 修复

- MCP 从网格打开编辑器后，正确初始化照片导航与胶片栏，支持快速切图。
- 端口被占用时显示明确错误，可修改端口后重新启用。
- 重新授权外接卷时同步卷与目录身份；增量扫描检查文件标识变化，保留照片 ID 和用户标注。旧指纹不符的调整继续暂停应用。

## 图库与升级

沿用 0.3.0 图库格式，本次不新增格式升级。0.2.x 或更早图库仍在写入前拒绝打开，保留原库与恢复日志，不执行迁移或创建替代空库。需要继续使用旧图库的用户应保留匹配的旧版镜序；请先阅读 [0.3.0 图库说明](https://github.com/beihai0xff/JingXu/blob/v0.4.0/Documentation/Release-0.3.0.md)，不要删除原图库或数据容器。

## 验证范围

完整检查包含 Debug／Release 构建、29 项发布脚本测试及 29 组应用回归；覆盖保存失败与重试、手动改参、文件重扫后的旧请求拒绝、并发互斥、备份失败、事务回滚、批量撤销、取消、重名保护及预览元数据移除。

本机隔离图库的沙盒应用已完成实际 Codex 图片接收、JPEG／Sony A700 ARW 调色与撤销、三张混合批量、系统目录授权、成片导出及重新打开。RAW 预览为 2,048 × 1,366，成片为 4,272 × 2,848，原片哈希不变。已实测快速切图、密钥重置、端口冲突、关闭／重启、导出目录替换、取消与显式 MCP 会话关闭后保留已写入文件，以及只读磁盘映像离线和重新授权后的恢复。

未覆盖跨 macOS 版本、所有相机 RAW 格式、实体外接盘硬件矩阵、Homebrew 跨版本覆盖安装及 Gatekeeper 下载后首次启动。辅助功能工具仍不能稳定解析完整调色面板；实际滑块焦点与输入法组合输入不作为已验收项。显式 MCP 会话关闭测试不等同于全部网络故障。未经 Apple 公证；若系统拒绝启动，请勿关闭系统安全保护。发布流水线另行核对合入提交、签名、DMG 完整性及 GitHub 资产摘要。
