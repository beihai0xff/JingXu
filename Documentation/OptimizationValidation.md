本轮在已有未提交优化代码上继续修改；素材、隔离数据库和临时验收应用均位于仓库外。没有安装、发布或访问个人图库。

本地图库和系统照片每次向相邻方向取最多 200 项，成功后才按完整网格行裁剪到约 600 项；失败保留原窗口和重试入口。显式选择与载入窗口分离，窗口外焦点摘要供检查器、查看和方向键使用。状态栏分别显示当前载入与匹配总数。系统照片在刷新时按可见照片 ID 重新定位，图库顺序变化导致页面重复时重新锚定。

`BrowsingPerformanceProfile` 在仓库外生成同一份十万条目录与一张 4,000 × 3,000 合成 PNG。每个载入量、每条路径都在独立 Release 进程执行，素材生成不计入峰值内存。`whole` 重放原来的整段详情刷新、版本字典和全尺寸首图逻辑；`changed` 使用局部更新和实际的 Core 预览会话。它是受控路径对比，不是两个版本应用的窗口跑分，也不模拟 iCloud 网络。
