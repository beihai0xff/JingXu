# 导入与后台可靠性优化验证

验证日期：2026-09-12。实现分支：`codex/import-and-background-reliability`。

本文记录实现阶段的验证快照；后续 0.4.6 发布的功能与验收边界见 [版本说明](Release-0.4.6.md)，源提交由发布流水线附入 GitHub Release。

## 已实现

- 导入预检与固定清单确认；目录、分组、复制和索引错误分别呈现，最近一次结果持久保存，重启后中断任务可重新预检。
- RAW/JPEG 及明确关联 XMP 成组避让；视频独立处理。检查已有编号候选，支持部分组补齐，防止重复导入产生额外副本。
- 普通与调色缩略图共用后台缓存，按照片直接失效、限制容量、回收旧修订，隔离清理前的请求。
- MCP 连接同步注册，请求任务由服务跟踪；关闭等待控制器、流与请求收尾后再关闭事件循环。
- 索引完成即刷新图库，分析期间节流刷新并保留操作互斥与标注保护。

使用规则见 [安全导入](SafeImport.md) 和 [缓存与后台任务](BackgroundWork.md)。

## 本次验证结果

- 在项目根目录执行 `zsh Scripts/build.sh check`：Debug／Release 构建、47 组 JingXuChecks、29 项发布脚本检查通过。
- 导入覆盖局部目录权限、模糊配对、两种 XMP、照片与视频同主名、编号空洞、重复重试、文件替换／消失、取消、部分提交、竞争目标、容量不足、数据库失败及 2,001 项完整范围。所有文件操作样本均为隔离测试材料；模拟 RAW 用于文件操作校验，不代表真实 RAW 解码验收。
- 缓存覆盖清理与写入竞争、重启后修订保护、容量淘汰、屏幕比例、写入失败。5,000 个缓存文件／1,000 个不匹配照片 ID，5 次失效耗时中位数 48 ms，低于 500 ms 验收目标；这是同机合成样本，不是实际界面耗时。
- `SWIFTNIO_STRICT=1` 下，100 次并发请求／关闭／重启通过，并覆盖初始化竞争及实际 HTTP SSE 流关闭；未出现向已关闭事件循环调度的警告。
- 独立源码副本通过 `zsh Scripts/build.sh adhoc` 的完整构建回归、应用签名与 DMG 校验。未覆盖已有安装包，未修改版本元数据，未合入 GitHub 或发布。
