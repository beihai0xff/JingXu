# 镜序 0.5.0

构建 26，macOS 14+、Apple Silicon。

## 浏览与连续选片

- 网格改为每页 200 项，支持前后翻页和跨页单图导航。搜索停止输入 300 ms 后更新，回车立即提交；中文输入法组词期间等待确认。查询失败保留上次成功结果，并提供重试入口。
- 同一筛选下保留跨页显式选择，状态栏显示本页、完整匹配、已选和其他页已选数量。「全选本页照片」只追加本页。切换来源、目录、相册或筛选后清空选择。
- 打开单图保留网格批选；单图操作只作用当前照片，返回网格恢复有效批选。支持 0–5 评分、Shift 加评分后前进、Delete 淘汰和 U 取消淘汰；多选时 Delete 只批量标记。
- 批量修改评分、旗标、关键词和相册成员在同一事务中完成。关键词支持追加、移除及确认后替换。Command-Z／Shift-Command-Z 撤销、重做本次涉及的字段，保留独立字段修改；关键词草稿在切图和文件操作前保存。

## 双图比较

- 选择两张照片进行比较，或从质量检查器打开相似组。左侧固定参考图，右侧候选接收评分、淘汰和关键词操作；可将候选设为新的参考图。
- 默认联动缩放和平移，支持适应窗口、物理像素 100% 和独立查看。保留两张活动大图及一张候选预取，退出释放图像。相似组不自动选出最佳照片，也不启用新的模糊报警。

## 可靠性与输出

- 普通与调色缩略图合并同键请求，单个订阅取消不影响其他订阅。失败显示原因并可重试或重新授权来源。
- 照片计数与后台进度分别显示，批量操作展示作用数量；维护入口收在「整理」菜单。
- XMP 经固定清单确认后仅创建新文件。已有文件、符号链接和多个照片指向同一 XMP 均跳过；提交时再次核对来源、照片身份和标注，并使用原子不覆盖提交。已删除整份替换入口。
- MCP 从完整选择 ID 读取跨页目标，继续核对选择和编辑版本；单图及比较模式仅暴露当前活动照片。

## 安装与验证边界

本版本按仓库既有通道作为 ad-hoc 签名、未经 Apple 公证的测试预发布版提供。安装前结束后台任务、退出旧应用并备份图库，保留系统安全保护。发布流水线执行本提交的构建回归、应用签名验证、DMG 完整性和 GitHub 资产摘要校验。

本机代码验证通过 51 组 JingXuChecks 及 29 项发布脚本检查，覆盖 XMP 竞争、批量字段撤销与事务回滚、跨页查询、缩略图取消、双画布几何和既有导入／调色／MCP 链路。十万条合成数据遍历 500 页无重复或遗漏；分页连同完整匹配计数的 P95 为 9.0 ms，这是同机 SQLite 查询耗时，不代表界面延迟。

Mac 锁屏阻止了本次原生交互实测。中文输入法与键盘焦点、跨页批选返回、双图缩放／快速切候选、Sandbox 重新授权及系统分享交互尚未验收。真实 RAW、真实图库覆盖升级、跨设备 Gatekeeper 安装和 Homebrew 升级也未验收；自动化检查不能替代这些结果。

操作规则见 [浏览与选片](https://github.com/beihai0xff/JingXu/blob/v0.5.0/Documentation/BrowsingAndCulling.md)，本机检查记录见 [优化验证记录](https://github.com/beihai0xff/JingXu/blob/v0.5.0/Documentation/OptimizationValidation.md)。
