# 镜序 0.2.7

本版为 ad-hoc 签名、未经 Apple 公证的预发布版。安装包为 `JingXu-0.2.7-test.16-macOS-arm64.dmg`，发布后同步 Homebrew Cask；可能被 Gatekeeper 拦截，请勿关闭系统安全保护。

## 选片与快捷键

- 旗标只保留「未标记」和「淘汰」，同步简化筛选、照片徽标和 XMP 导出。
- 用 Delete（⌫）或前向 Delete（⌦）标记淘汰，保存成功后自动选择下一张照片；不直接删除文件。
- 网格和单图预览均支持自动前进，跳过视频；在「未标记」筛选下，当前照片隐藏后仍能正确前进。
- 最后一张不循环，保存失败不跳转，长按 Delete 不会连续淘汰；保存期间主动切图或更改筛选不会被自动跳转覆盖。
- U 取消当前照片的淘汰标记并停留；直接点击旗标选项也停留。输入文字、输入法组合输入及弹窗保持原有按键行为。

## 升级说明

macOS 14+、Apple Silicon；构建 16。升级前完成或安全取消后台任务、解决恢复提示、退出应用并备份图库。

本版移除了旧「保留」（`picked`）状态，不提供兼容或自动转换。旧图库若含有此状态，请在旧版中先将这些照片改为「未标记」，否则新版读取相关标注会失败。Bundle ID 和图库位置不变，不自动移动或删除原照片。
