# 镜序 0.6.3

构建 30，macOS 14+、Apple Silicon。

## 单图返回时保留完整照片页

- 修复打开单图后返回网格时，当前照片之前的图片从本页消失的问题。原因是旧实现把当前照片作为新页起点，并非原文件被删除。
- 当前照片仍在原页时，返回后保留整页和有效批选；跨页浏览后，加载当前照片所在的完整页，每页仍最多 200 项。
- 网格重建时定位当前照片；当前照片已不匹配筛选时，按排序位置返回最近的存续页。目录、搜索和排序范围保持一致。
- 不改变数据库格式，不移动或删除原照片。

## 验证与安装边界

本版本沿用 ad-hoc 签名、未经 Apple 公证的测试预发布通道。安装前结束后台任务、退出旧应用并备份图库，保留系统安全保护。发布流水线对发布提交执行 Debug／Release 构建、完整回归、应用签名验证、DMG 完整性及 GitHub 资产摘要校验。

本次实现已通过本地统一构建回归，新增检查覆盖 2,005 项、两种时间排序、页首／页尾、小目录最后一张、目录范围、当前照片被筛选隐藏及空范围。同一修复已用升级版本号前的 0.6.2（29）本地测试包备份后覆盖安装，签名及应用文件一致性核对通过，并确认能够启动及打开单图。

点击返回时原生界面自动化连接中断，重连仍失败，因此返回网格后的实际内容、跨页返回与滚动定位尚未完成界面验收。GitHub 生成的 0.6.3（30）产物也尚未完成下载后 Gatekeeper 安装、Homebrew 升级及全新 Sandbox 目录授权验收，不将 Core 校验或本地应用启动视为这些验收通过。
