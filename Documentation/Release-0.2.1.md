# 镜序 v0.2.1

macOS 14+ · Apple Silicon · build 8

## 更新

- 单图底部新增横向胶片栏：缩略图、文件名、评分、旗标与当前照片高亮，点击和方向键切图同步。
- 重做大图可见区域绘制，针对持续花屏问题增加清帧和过期加载隔离。
- 质量分析 v2：双尺度局部纹理分析，曝光和连拍信息不再直接产生质量警告。人工校准未通过前默认关闭模糊报警。
- 支持确认后重新分析、断点进度与升级备份保护；重算不修改用户评分、旗标或标签。

## 安装与数据

下载 `JingXu-0.2.1-macOS-arm64.dmg`，退出所有旧版镜序，先备份数据容器，再将镜序.app 拖入应用程序并替换。停用其他目录的旧副本。

Bundle ID、沙盒权限和图库路径不变；迁移前自动备份。不要删除数据容器。恢复备份会回退备份之后的标注；降级需同时恢复对应数据库备份，不可只换旧应用。
