# 镜序 0.8.0

构建 33，macOS 14+、Apple Silicon。

## 系统照片与 iCloud 相册

- 通过 Apple PhotoKit 浏览系统照片和普通相册，支持每页 200 项、跨页选择、单图缩放与导航。
- 从本地图库上传原片或调色 JPEG，确认固定清单后创建照片并加入目标相册，保留本地来源。
- 新建、改名和删除普通相册，添加或移出成员；移出和删除相册保留照片。图库照片删除使用独立确认，由系统「最近删除」提供恢复。
- 单图调色与裁剪自动保存本机草稿，明确点击「保存到系统照片」才更新同一照片；保留 Apple 原片，并检测外部编辑冲突。
- 手动分析确认的所选照片，支持暂停与继续，结果和人工审核保存在本机。Live Photo 仅支持静态浏览、整理和分析，不回写编辑。

镜序不要求 Apple 账户密码，不提供第三方云接口。iCloud 同步由 macOS 负责；系统提交成功不代表云端同步完成。视频、共享相册及系统照片 MCP 控制不在本版范围。

## 验证与安装边界

本版本为 ad-hoc 签名、未经 Apple 公证的测试预发布版。安装前结束后台任务、退出旧应用并备份图库，保留系统安全保护。

功能实现已通过 Debug／Release 构建、55 组回归和 29 项发布脚本检查；系统照片专项使用假图库，覆盖 2,005 项跨页选择、相册语义、上传、草稿、权限撤销、冲突、取消和中断恢复。发布流水线会再次对发布提交执行完整构建回归、签名与资产摘要校验。

隔离界面已验证系统照片入口、多选、单图入口、分析暂停与继续，以及原片上传确认流程；隔离提交记录确认上传完成且来源保留。界面自动化连接中断，上传成功提示、相册操作及调色／裁剪交互尚未完成原生界面验收。

**真实系统照片和 iCloud 跨设备同步尚未验收。** 当前没有独立 macOS 测试用户及专用 Apple 账户；假图库不能替代真实 PhotoKit 权限、原片保留、RAW、第三方编辑和跨设备验收。Gatekeeper 首次安装、覆盖升级及实际 Homebrew 升级亦未验收。
