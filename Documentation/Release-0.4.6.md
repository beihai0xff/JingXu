# 镜序 0.4.6

构建 25，macOS 14+、Apple Silicon。

## 导入更可控

- 导入前生成固定清单，展示目标目录、照片组、复制大小、重复项及失败原因。存在不可读子目录或无法明确配对的文件时，确认后可继续导入可处理的部分。
- RAW、JPEG 和明确关联的 XMP 成组命名，避免同组文件因重名分散；视频独立处理。检查已有编号候选，重复导入不再因编号空洞生成额外副本，已导入一部分的文件组可补齐缺失文件。
- 最近一次导入结果持久保存，区分复制失败、索引失败、部分完成和中断。重试重新预检来源与目标；执行前后核对文件身份和内容，保留不覆盖提交、容量检查、取消及异常停止机制。

## 缓存与后台任务

- 普通与调色缩略图共用后台缓存，按照片直接失效，限制磁盘容量并回收旧修订；清理或切换修订后，过期请求不能重新写入旧缓存。
- MCP 关闭时先停止接收新请求，等待控制器、请求和连接收尾，再关闭事件循环，避免退出或快速重启时向已关闭事件循环提交任务。
- 索引完成后立即显示照片，质量分析期间按节奏刷新结果，支持浏览、筛选和标注，继续保留文件操作互斥及人工标注保护。

## 安装与验证边界

当前采用临时签名，未经 Apple 公证，以测试预发布版提供。安装前结束后台任务、退出旧应用并备份图库，不关闭系统安全保护。

本机统一入口的 Debug／Release 构建、47 组应用检查及 29 项发布脚本测试通过。导入覆盖目录权限、两种 XMP、照片与视频同主名、重复重试、文件替换或消失、取消、部分提交、目标竞争、容量不足、数据库失败及 2,001 项完整范围。缓存覆盖清理与写入竞争、修订保护、容量淘汰和写入失败；MCP 在严格模式下完成 100 次并发请求／关闭／重启，并验证实际 HTTP SSE 流关闭。

已建立独立应用标识和 Sandbox 图库，但 Mac 锁屏阻止本次原生界面操作。导入预检清单、部分完成报告、重试，以及分析期间浏览／筛选／评分的实际界面验收尚未完成。真实 RAW 解码、真实图库覆盖升级、跨设备 Gatekeeper 安装及 Homebrew 升级未验收。自动化检查不等同于这些验收；发布流水线继续执行应用签名、镜像完整性和 GitHub 资产摘要校验。
