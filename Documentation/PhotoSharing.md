# 多选照片与 macOS 系统分享

## 选择范围

网格单击替换选择，⌘ 点击增减，Shift 点击选择锚点与当前照片之间的连续范围，⌘Shift 点击追加该范围。没有有效锚点时使用当前焦点照片；焦点也无效时从点击的照片开始。连选按网格顺序跳过视频，最多包含当前显示的 2,000 项。

保留「批量选择」勾选模式；双击只切换一次勾选，不打开单图。普通模式的无修饰双击仍打开单图。切换目录清空选择；筛选或刷新移除不可见选择，筛选改变时重置锚点。

移动、批量调色、成片导出和分享使用同一照片选择集合。评分、Delete 淘汰并下一张、U 取消淘汰仍只针对焦点照片，不对多选集合批量标记。评分、旗标与关键词分别在数据库事务中保存自己的字段，交错操作保留其他最新标注；失败不前进。单图工具栏分享只针对正在查看的一张，即使它因旗标筛选而从网格隐藏。

## 分享

1. 点击网格操作栏、单图工具栏或菜单中的「分享…」。
2. 核对数量和文件清单，选择「分享原片」或「分享调色成片」。两者均可能包含 GPS 位置等拍摄信息。
3. 点击「准备分享」，等待准备完成。可取消；失败项逐项列出，可重新准备。存在失败项时，必须勾选「仅分享成功项」才能继续；全部失败不会打开系统菜单。
4. 再点击「系统分享…」，自行选择 macOS 提供的目标。镜序不硬编码收件应用，也不自动发送。

原片直接使用原文件 URL，不复制、不转换，也不要求先成功解码。只交付明确选中的文件，不附带未选中的 RAW/JPEG 配对文件或 XMP。来源离线、授权失效、路径或文件身份变化时跳过并说明。系统服务可能不支持 RAW、HEIC 或特定数量；镜序不会因此偷偷转成 JPEG。

调色成片先等待当前编辑保存成功，再冻结文件信息和调色修订。默认原尺寸 JPEG、品质 92%、sRGB，应用正确方向并保留 GPS、EXIF 等现有导出策略支持的拍摄信息。可选择最长边 2,048 像素，不放大小图；没有调色记录时使用默认参数。RAW 依赖系统完整解码，无法解码的项目单独失败。此选项不改变「导出成片」原有格式或尺寸默认值。

## 文件与会话保护

- 准备过程串行处理，只写应用自己的分享缓存，不批量保留原图，也不将成片加入图库。同名成片追加序号，不覆盖。未交付系统的取消任务立即清理。
- 原片待分享及服务运行期间持续持有来源访问授权，阻止扫描、删除、移动、归档、来源管理等文件操作；准备过程与现有任务互斥，未完成的恢复日志需先解决。
- 选择服务后可继续浏览，不使用长期工作状态锁住侧栏。系统自身的模态界面可能暂时限制交互。
- picker 未选择服务就关闭时结束会话；服务的成功、失败或取消回调释放状态。某些外部应用不提供终态回调，可使用「结束本次分享会话…」。它只释放镜序持有的资源，可能导致未完成的原片分享失败，**不能撤回或停止外部应用发送**。
- 原片会话未结束时退出应用会询问「留在镜序」或「结束会话并退出」。成片已交付后的缓存至少保留 24 小时，长时间活动会话不清理；结束时再延长一天。下次启动或准备分享时回收过期目录。
- 文件可能被镜序之外的软件改变；准备时的检查不能保证外部应用稍后读取一定成功。完成提示只表示系统服务回调，不代表收件人已收到。

不修改原照片、评分、旗标、标签或相册关系，不新增数据库迁移、服务、遥测或 Sandbox 权限。

## 验证

运行完整构建与回归：

    zsh Scripts/build.sh check

多选与分享检查已接入 JingXuChecks 主链，也可运行构建好的 JingXuChecks --sharing-checks：

- ⌘/Shift/⌘Shift、反向范围、失效锚点、视频、2,000 项顺序、双击去重。
- 原片 URL 直传（含不能解码的合成 RAW/JPEG/HEIC）、选择隔离、重复路径、文件替换、离线和损坏授权。
- 合成 JPEG／HEIC 成片、方向、原尺寸／2,048 像素、GPS、调色修订、原片与用户标注不变。
- 空间错误、无法写入缓存、解码失败、取消、并发准备、同名编号、既有缓存保护。
- 注入 picker 的取消、成功、失败、重复／过期回调、无回调手动结束、部分成功确认、退出保护状态与缓存寿命。

JingXuChecks --sharing-ui-fixtures 在仓库外生成仅含合成图片的独立图库。启动 UI 验证时必须将 JINGXU_UI_TEST_ROOT 设为返回路径，同时隔离数据库、日志和缓存；不能用真实图库试分享。

CLI 注入服务不等于 macOS 服务或沙盒授权验收。真实接收仅可使用合成图片与用户指定的接收端；没有指定接收端时不发送。实际 UI、沙盒与 XCUITest 执行结果需按本次交付记录，不引用历史验收。
