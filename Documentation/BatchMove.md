# 批量选择并移动照片

网格支持 ⌘ 点击增减、Shift 连选、⌘Shift 追加范围；也可开启「批量选择」逐张勾选，或「全选本页照片」／清空选择。移动、调色、导出与分享读取同一选择集合。范围为同一筛选内跨页显式选择的完整照片 ID，视频不可选择；不受当前加载页限制。翻页保留选择；用户切换筛选后清空选择；实际不再匹配或失效的目标移出选择。[多选与分享说明](PhotoSharing.md)

来源目录树可限定当前网格范围，默认包含子目录。切换目录或「包含子目录」开关会清空全部选择，避免移动上一目录的照片；移动／撤销完成后目录树自动更新。空磁盘目录仍保留，不会自动清理。[目录浏览说明](FolderBrowsing.md)

点击「移动到目录…」，选择同一磁盘上的目录，核对旧路径、目标来源及相对路径、文件数、大小和跳过原因，再授权并移动。此功能不自动执行，不复制、不覆盖已有文件。原路径失效，外部软件不会自动更新。

原片分享会话结束前不能移动照片，避免外部分享服务失去原路径；可以继续浏览，完成分享或明确结束会话后恢复移动入口。

- 同磁盘的来源内子目录、其他来源及来源外目录均可作为目标。未登记目录只在一组移动成功并提交数据库时登记；已有来源内的目标复用来源，不创建子来源。评分、标签、照片 ID、相册关系、分析和导入时间保留，跨来源时更新来源 ID。
- RAW/JPEG 配对须全部选中；明确关联的 XMP 一同移动并列入清单。同组有未索引同名媒体或关联不明确时整组跳过。不移动视频及其他未选中照片。
- 重名整组追加一致序号，不按内容去重。已经在目标位置的文件不处理。无需 EXIF 日期。
- 跨磁盘、离线、过期权限、符号链接，以及重复／父子来源产生的多重索引冲突保守拒绝或跳过。目标目录身份发生变化时不移动。
- 与日期归档共用备份、持久日志、互斥与恢复机制。「恢复未完成归档…」「撤销最近一次归档…」同样用于此移动任务。取消仅停止后续组；部分失败尝试无覆盖回退，不能安全回退时暂停并保留日志。撤销不会删除新登记的空来源。

实现没有修改数据库结构。旧程序不理解跨来源移动日志，因此有未解决移动任务时禁止手动换回旧版。恢复与撤销须使用此版或更新版本，数据库备份本身不等于撤销文件移动。

自动检查使用独立临时文件验证跨来源、重名配对、评分标签保留、未选中照片保留、撤销与移动后提交前中断恢复。实际沙盒授权、跨卷拒绝和界面鼠标交互仍需在打包应用中人工验收；不会用真实图库试移动。
