# 来源目录树与文件夹浏览

左侧「来源」按已索引的相对路径展示目录树。点击箭头展开／折叠，点击目录名称浏览；同层采用自然排序。来源根节点始终保留，子目录只展示含已索引照片、视频或这些媒体的下级目录，不显示未索引的磁盘空目录。

目录旁的数字是包含子目录的**图库索引总数**，不受搜索、评分、旗标影响，也不是实时磁盘文件数。来源离线后仍保留目录与索引，已有缩略图可继续浏览；缺失文件的记录须通过「清理失效索引…」核实后移除，不会因展开目录自动清理。

## 当前范围

- 内容区显示目录路径，「包含子目录」默认开启并记住设置；关闭后只显示直接位于该目录中的媒体，来源根目录同样适用。
- 切换目录保留搜索、评分和旗标。筛选只影响照片列表，不隐藏目录树；没有直接文件时可开启子目录，没有匹配结果时可清除筛选。
- 网格及单图导航仍最多 2,000 项。状态栏分别显示完整匹配数量与已显示数量；目录树和目录数字不受显示上限限制。
- 切换目录或子目录开关会返回网格、清空单选与多选、更新 AI 选择范围。正在调色时必须先保存成功；保存失败则保持当前照片、目录和开关。确认清单、文件操作或 AI 操作占用期间不能切换范围。
- 扫描、导入、移动、归档、撤销或清理后更新目录树；取消或失败也重新读取已提交的索引。选中目录消失时回到最近仍存在的上级目录；来源移除后回到全部图库。磁盘上的空目录不会被删除。

| 操作 | 范围 |
| --- | --- |
| 清理淘汰图片、清理失效索引、重新分析当前范围 | 当前来源／目录及筛选的完整匹配范围，不限 2,000 项 |
| 批量移动、批量调色、导出 | 已明确选择的照片；切换目录会清空选择 |
| 按日期重新归档、重新分析全部旧结果 | 整个图库，不受所选目录影响 |
| 重新扫描整个来源 | 所选目录所属的整个来源，不是只扫描当前子目录 |
| 移除来源 | 仅来源根节点提供；清理整个来源的索引和标注，不删除原文件 |

本功能只读索引，不会为子目录新建来源、改变数据库格式、移动或重命名照片。不提供子目录删除、拖动整理或未索引文件浏览。

## 实现与校验

`CatalogFolderNode` 使用来源 ID 和原始相对目录作为稳定身份。树在 Core 后台从路径字段聚合；筛选使用现有 `(sourceID, relativePath)` 索引的 BINARY 前缀区间与路径段边界，不使用忽略大小写的 `LIKE`。目录范围缺少来源 ID 或含上级跳转时直接报错。

`AssetQuery` 的 `relativeDirectory` 与 `includeSubdirectories` 接入统一查询；计数忽略分页，清理与重算保留目录条件。列表响应带请求代次及查询复核，快速切换时只提交当前请求；目录树仅在索引结构刷新时重建。

侧栏及「包含子目录」的禁用样式只依赖模型发布的状态，不能在 SwiftUI 渲染时读取 `NSApp.modalWindow` 或 `attachedSheet`。结果提示关闭时，模型可能先清空提示，AppKit 随后才移除 sheet；后者不触发模型通知，会导致整个侧栏一直保留禁用样式。系统弹窗检查保留在实际切换入口，确认清单、后台操作、调色保存及 AI 占用的门禁不变。

运行 `zsh Scripts/build.sh check`，包含完整 Debug／Release 构建与 `JingXuChecks`。新增检查覆盖层级、根目录、空目录、离线、视频、同名来源／父子来源、大小写、中文、空格、通配符、组合 Unicode、2005 项范围、清理后回退，以及移动和撤销后的目录更新。10 万条模拟索引检查树构建耗时、目录首批＋计数耗时和校验进程峰值内存。

独立 UI 素材可由构建后的 `JingXuChecks --folder-ui-fixtures` 生成，命令返回全新临时图库根目录。启动开发应用时必须显式将 `JINGXU_UI_TEST_ROOT` 设为该目录，不能仅选择临时照片文件夹。UI 验收应覆盖箭头与名称的分离、展开层级、筛选、子目录开关持久化、单图胶片栏、多选清空、调色保存失败和快速连续切换。
