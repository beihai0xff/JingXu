# 镜序 0.2.8

本版为 ad-hoc 签名、未经 Apple 公证的预发布版。安装包为 `JingXu-0.2.8-test.17-macOS-arm64.dmg`，发布后同步 Homebrew Cask。

## 大图与全屏浏览

- 双击照片进入大图模式，默认收起侧栏、搜索、筛选和整理工具，让照片占据更多空间；macOS 全屏下同样生效。
- 看图控制压缩为一行，移除重复的文件名、尺寸和操作提示。文件信息、评分和标记通过右上角信息按钮按需查看。
- 胶片栏缩小为紧凑缩略图，可用右上角胶片栏按钮收起；切换照片后保持显示设置，悬停查看文件名。
- 照片保持原始比例，适应窗口时完整显示；保留 100% 查看、缩放、方向键切图、Delete 淘汰并下一张、U 取消标记和 Esc 返回网格。
- 仅加载失败时显示重试按钮；进行中的后台任务仍显示进度和取消操作。

## 安装与升级

macOS 14+、Apple Silicon；构建 17。Homebrew 用户退出镜序后运行：

```sh
brew update
brew upgrade --cask beihai0xff/jingxu/jingxu
```

升级前完成或安全取消后台任务、解决恢复提示、退出应用并备份图库。Bundle ID 和图库位置不变，不自动移动或删除原照片。

从 0.2.6 或更早版本升级，请先在旧版中将「保留」旗标改为「未标记」；新版不兼容旧 `picked` 状态，也不自动转换。
