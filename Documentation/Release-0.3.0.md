# 镜序 0.3.0

离线、非破坏式基础调色：在镜序中调整照片、保存预设，并导出独立成片。原照片内容保持不变。

本版为 ad-hoc 签名、未经 Apple 公证的预发布版。macOS 14+、Apple Silicon；构建 18。安装包为 `JingXu-0.3.0-test.18-macOS-arm64.dmg`，发布后同步 Homebrew Cask。

## 图库格式变更：升级前必读

0.3.0 使用新图库结构，**不迁移 0.2.x 或更早图库**。旧格式在写入前拒绝打开，数据库、日志及恢复入口保留，不清空数据，也不创建替代空库。

需要继续使用旧图库的用户应保留匹配的旧版镜序；不要直接覆盖安装后期待旧图库自动升级。新版目前没有图库切换界面，已有旧图库的账户不适合直接升级试用。测试新版本请使用独立 macOS 测试账户或开发文档所述的隔离图库环境，不要删除原图库或数据容器。新旧版不能同时运行。

## 调色与成片

- 单图新增曝光、对比度、高光、阴影、白色、黑色、色温、色调、饱和度、鲜艳度；支持原图对比、重置、会话撤销／重做。
- 停止输入 300ms 或结束拖动自动保存；离开预览或退出前等待保存，失败保留草稿并允许重试或明确放弃。
- RAW 使用系统 `CIRAWFilter` 完整解码，不支持的相机格式禁用调色和成片导出。普通图片使用相对色温，RAW 支持拍摄时与绝对白平衡。
- 缩略图、胶片栏和单图应用已保存调整，显示「已调色」标记；成片直方图与原片质量诊断独立。
- 保存、重命名和删除自建预设；复制调整或应用预设时选择明暗、白平衡、色彩组，批量操作仅作用于当前选择，确认后备份并在单个事务内提交，支持撤销。
- 严格导入受支持的 Lightroom 基础 XMP 参数；未知效果、曲线、HSL、蒙版、相机配置及非法数值均拒绝。导入后由镜序渲染，不保证与 Lightroom 成片一致。
- 导出原尺寸 sRGB JPEG（92%）、PNG 或 16 位 TIFF；保留拍摄元数据、更新方向与尺寸，重名跳过，以临时文件编码后原子且不覆盖地提交。取消保留已完成成片，不自动重新导入。
- 文件变化后保留调整记录并暂停应用；移动与撤销保留调整，来源合并遇到不同调整时跳过并说明冲突。

详细操作、XMP 白名单和技术边界见 [调色文档](ColorEditing.md)。首版不包含曲线编辑器、HSL、局部蒙版、AI 修图或 LUT。
