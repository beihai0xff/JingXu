# 镜序 0.9.3 测试版

构建 37，macOS 14+、Apple Silicon。

## 浏览与交互

- 本地图库和系统照片仍按每次 200 项载入，滚动网格只保留邻近的约 600 项；向上返回时重新按需载入缩略图。
- 显式选择不受载入窗口裁剪影响。窗口外的焦点照片仍可查看、检查并用方向键继续选片；状态栏区分当前载入量和匹配总数。
- 裁剪时按可见照片恢复网格位置，调整网格大小或从单图返回时保留浏览位置。系统照片在图库变化后按可见照片重新定位。

## 可靠性

- 系统照片切图在读取新照片失败时保留原画面和本机草稿，支持重试；完整画质按需要求，普通预览减少解码负担。
- 文件整理遇到权限或文件状态不明时保留日志并暂停，避免误判为文件已不存在。导出在确认目标可写且不覆盖后才渲染。
- 大图库的局部标注与刷新减少重复查询，导入、分析和缓存的取消及失败路径补充隔离检查。

## 验证与安装边界

本地统一入口完成 arm64 Debug／Release 构建、发布脚本检查及功能回归；十万项本地目录、超过 2,000 张假系统照片的双向分页和固定选择范围已在隔离数据中检查。隔离原生应用复查了两种图库裁剪后的往返滚动、窗口外焦点和单图返回。细节与内存采样见 [优化验证记录](OptimizationValidation.md)。最终发布提交仍由 GitHub Actions 再次构建、签名和核对资产摘要。

本包使用 ad-hoc 签名，未经 Apple 公证，以测试预发布版提供。安装前结束后台任务、退出旧应用并备份图库。真实 PhotoKit 授权、iCloud 跨设备同步、真实 RAW、Gatekeeper 首次安装、覆盖升级和实际 Homebrew 升级尚未验收；隔离假服务与短时内存采样不替代这些检查。若系统拒绝启动，不要关闭系统安全保护。
