# 镜序 0.6.1

构建 28，macOS 14+、Apple Silicon。

## 图片时间排序

- 搜索栏新增图片排序菜单，可选择「时间：最老在前」或「时间：最新在前」。默认最老在前；缺少拍摄时间时使用文件修改时间，同时间按文件名和资源 ID 稳定排序。
- 网格分页、单图导航、胶片栏和相似组比较使用一致的排序规则。切换排序回到第一页并清空选择，当前会话中切换目录和筛选时保留排序方式。
- 补齐最老在前的全库及来源查询索引，保持大图库分页性能；不修改原照片。

## 安装与验证边界

本版本沿用 ad-hoc 签名、未经 Apple 公证的测试预发布通道。安装前结束后台任务、退出旧应用并备份图库，保留系统安全保护。发布流水线执行发布提交的 Debug／Release 构建、完整回归、应用签名验证、DMG 完整性和 GitHub 资产摘要校验。

本次功能已通过本机统一构建回归。新增检查覆盖两种时间顺序、缺少拍摄时间、同时间同名图片、正反向分页、包含锚点刷新、照片导航范围、跨批次选择顺序和查询索引；十万项图库完整分页检查通过。

已在独立合成图库和独立应用标识下验证排序菜单布局、默认最老在前及切换最新在前后的网格顺序。该界面验证使用 Debug 应用；真实图库覆盖升级、Sandbox 目录授权、下载后的 Gatekeeper 安装和 Homebrew 升级尚未验收。未替换本机已安装应用。
