# 镜序 0.6.2

构建 29，macOS 14+、Apple Silicon。

## 来源目录层级与点击

- 左侧来源按完整磁盘路径嵌套在最近的已添加上级来源下，补齐中间目录，同层采用自然排序，修复父子来源被平铺的问题。
- 嵌套来源标注「独立来源」，保留自己的照片筛选、计数、重扫和移除范围。上级来源不额外累加独立来源的索引；同一路径被不同来源索引时不自动合并记录或标注。
- 修正目录行的选择标签，来源根、普通子目录和嵌套来源均可点击切换照片范围；只用于展示层级的中间目录仅支持展开。
- 不移动原照片，不改变数据库格式或来源归属。

本版本沿用 ad-hoc 签名、未经 Apple 公证的测试预发布通道。安装前结束后台任务、退出旧应用并备份图库，保留系统安全保护。发布流水线对发布提交执行 Debug／Release 构建、完整回归、应用签名验证、DMG 完整性及 GitHub 资产摘要校验。

本次目录实现已通过统一构建回归，检查覆盖父子来源、跨层中间目录、相似路径前缀、离线来源、重叠来源身份和计数隔离。包含相同目录修复的本地测试包已覆盖安装并启动，实际点击来源根、普通子目录及嵌套来源后，选中状态、路径和匹配数量均正确更新；箭头折叠和展开正常。旧应用和图库已备份，验收仅进行浏览操作。
