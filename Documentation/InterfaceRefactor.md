# 图库界面与交互重构

本轮依据已评审的原生简洁设计实现，业务范围与原片保护规则保持在现有 Core 协调器内。

## 页面与操作

- 图库默认两栏：来源侧栏与照片网格。搜索、筛选、视图选项位于顶部；信息与质量详情按需打开。
- 网格按 200 项连续载入。选择后出现操作条，全选查询完整范围，批量操作冻结明确选择。
- 单图顶部集中返回、切图、编辑、导出、分享和详情；下方放缩放、评分、淘汰及胶片栏。
- 编辑侧栏使用调整、裁剪、预设三个页签。参数自动保存；预设先预览后应用，裁剪保持明确的应用与取消。
- 导出在一个窗口内选择格式和目录、预检并确认固定清单；完成后展示成功、跳过及失败原因。
- 系统照片采用相同浏览与编辑结构。本机草稿与保存到系统照片分别表达；共享入口分享明确展示的静态画面。

## 旧代码清理

- 移除旧分页入口中已无调用方使用的反向载入、指定页偏移参数；连续载入和单图跨批次导航继续使用原查询机制。
- 移除未调用的关键词更新入口、未使用的撤销任务句柄及胶片单元的环境对象依赖；查询与胶片数据直接读取现有状态，质量详情直接使用现有组件。
- 删除仓库内没有引用的路径拼接包装、扩展名汇总、临时数据库工厂和未接入检查的通用失败注入接口。权限、提交失败、下载失败和中断恢复的实际检查保留。
