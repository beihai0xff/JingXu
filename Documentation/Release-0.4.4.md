# 镜序 0.4.4

构建 23，macOS 14+、Apple Silicon。

## 新功能与修复

- 网格支持 ⌘ 点击增减、Shift 连选与 ⌘Shift 追加范围，保留「批量选择」勾选模式；视频不进入照片多选。移动、调色、导出和分享使用同一选择集合，评分与淘汰快捷键仍只针对焦点照片。
- 网格与单图新增系统分享入口。原片直接交付原文件，不复制、不转换，也不自动附带未选中的配对文件或 XMP。
- 可分享已调色 JPEG：默认原尺寸、92% 品质、sRGB，保留 GPS；可选最长边 2,048 像素。准备时冻结修订，逐项报告错误；部分失败需确认仅分享成功项。
- 分享支持取消、缓存回收、重复／过期回调隔离和退出保护。原片会话持有来源授权并暂停文件整理，选择系统服务后可继续浏览。外部服务缺少终态回调时可明确结束会话，但不能撤回或停止外部应用发送。
- 修复删除结果提示关闭后，左侧分类、来源目录与子目录开关可能一直无法点击的问题。
- 不更改数据库格式、图库路径或 Sandbox 权限；升级不自动扫描、删除、移动或重算真实照片。

## 安装与验证边界

本包采用临时签名，未经 Apple 公证；分享完成仅表示系统服务回调，不代表收件人已收到。分享原片或成片可能包含 GPS 等拍摄信息，请自行选择分享目标。

安装前先结束后台任务、退出旧应用并备份图库，将 DMG 中的「镜序.app」替换到「应用程序」。停用其他目录的旧副本，不关闭系统安全保护。原片与标注保存在应用包之外；恢复数据库不能代替撤销文件移动。

统一构建入口涵盖 Debug／Release、37 组 JingXuChecks 与 29 项发布脚本检查，包含合成 JPEG／HEIC 的方向、尺寸、GPS、取消、失败隔离与会话生命周期。实际外部接收、真实 RAW 成片、跨设备 Gatekeeper 安装及 XCUITest 未验收，不将构建或注入服务测试等同于这些系统验证。系统或目标应用不支持某种格式／数量时不会自动转换原片。
