# 镜序 0.2.5

## 新增：现有图库按拍摄日期归档

- 各来源内按 EXIF 拍摄日期整理为 `年份/YYYY-MM-DD/`，覆盖整个图库照片，不受 2,000 项显示上限影响。
- 同卷直接移动，不复制、不覆盖；RAW/JPEG 与明确关联的 XMP 配套处理，视频保留原位。
- 确认清单、写授权、在线图库备份、内容校验、持久恢复日志及撤销最近归档。
- 保留资源 ID、评分、旗标、标签、相册及分析审核；来源离线、身份冲突或日期缺失时跳过。

## 使用与升级

支持 macOS 14+、Apple Silicon。先退出旧应用，备份图库和照片，再打开 DMG，将镜序拖到“应用程序”替换旧版；停止使用其他目录中的旧副本。Bundle ID、图库位置不变，本次无需数据库迁移，也不会自动归档。

首次使用归档请先在独立测试来源试用。移动会使旧路径失效，其他软件不会自动更新；照片本身不会被复制备份。不要仅恢复数据库来撤销移动，请使用归档撤销入口。源文件已改变或原位置占用时不覆盖并报告。
