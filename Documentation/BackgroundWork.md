# 缓存与后台任务

## 索引后即可浏览

添加来源、重新扫描、导入建立索引后立即刷新照片列表，再进行质量分析。分析期间最多每秒刷新一次，完成时再刷新；请求版本检查避免旧查询覆盖新筛选结果。已选照片和单图预览继续沿用现有选择协调逻辑。

分析期间可浏览、切图、筛选和评分标注；导入、扫描、调色及文件整理继续互斥。取消保留已索引照片和已完成分析。网格每页 200 项，单图导航跨页；导入和分析按完整范围处理。单次标注不影响筛选成员时仅刷新目标，后台诊断按节奏更新当前页及胶片栏。任务进度独立于浏览数量和标注结果。质量算法、校准门禁和人工标注保护不变。

## 缩略图缓存

普通和调色缩略图共用后台缓存 actor，所有读写、失效和清理均在后台执行。每张照片独立存储，失效按照片 ID 直接定位；缓存键包含文件身份、内容版本、调色修订、渲染类型和物理像素尺寸。尺寸使用 256、512、1024、2048 四档，按屏幕比例选择。

内存缓存最多 600 项、256 MiB。磁盘缓存超过 1 GiB 时按最近使用顺序回收到 800 MiB；新版本成功写入后回收旧版本。正在处理的请求持有失效代数，清理后旧请求不能重新写回。缓存写入失败不阻止返回已经生成的缩略图。

旧的平铺缩略图是可重建缓存，首次使用新缓存时清理；不修改图库、标注或恢复记录。「设置 → 清理缩略图缓存」同时清理普通和调色缓存。

## AI 连接关闭

关闭连接首先停止接收新请求，再等待控制器完成已提交编辑、结束流和请求任务，最后关闭 NIO 事件循环。连接注册同步完成，避免异步注册任务落在事件循环关闭之后。并发关闭共用收尾任务；关闭完成前不能重启服务。

关闭或客户端断开不撤销已接受的编辑，已进入保存流程的编辑继续遵循原有保存与失败处理。认证密钥、Host、Origin、选择及调整版本校验保留。

自动化回归在 `SWIFTNIO_STRICT=1` 下覆盖请求／关闭竞争、并发关闭与重新启动，关闭后不能再向事件循环调度任务。
