# 浏览与选片

## 搜索与浏览

搜索文件名、相机、镜头或关键词。停止输入 300 ms 后更新，回车立即更新；中文输入法组词期间等待提交。百分号和下划线按普通文字处理。更新中保留上一份有效结果并显示进度，文件操作等待查询完成。查询失败显示原因与重试入口；操作范围始终来自成功应用的查询，不来自输入草稿。

图库默认显示侧栏与照片网格，详情按需打开。顶部集中搜索、添加、筛选、视图选项与整理入口；评分和旗标筛选收进弹层，已应用条件显示为可移除的标签。视图选项调整缩略图大小、文件名显示及时间排序。

首次载入 200 项，继续滚动时每次读取 200 项。网格只保留当前附近最多 600 项；向前或向后滚动会重新载入窗口外的页面。可选择「时间：最老在前」（默认）或「时间：最新在前」，按拍摄日期排序，缺失时使用修改日期；同日期按文件名和 ID 排序。更换排序或筛选从首批重载并清空选择。同一范围刷新保留当前窗口，载入失败保留已有照片与选择并提供重试。

追加批次复用当前总数，不重复统计；筛选变化或影响结果范围的操作才重新统计。标注及其撤销按实际改变的评分、旗标、关键词或相册关系判断范围影响，例如只有搜索条件时撤销评分无需重查范围。选择有效性只查询 ID，不加载全部所选照片的诊断和调色详情。局部变化按当前窗口 ID 索引更新；显式选择可保留窗口外照片。

单击选择，Command 点击增减，Shift 连选及 Command-Shift 追加限定当前载入窗口。「选择」进入逐张勾选模式；选择后网格上方显示评分、淘汰、比较、相册、导出和更多操作。「全选当前范围」与 Command-A 查询完整筛选的照片 ID，包含尚未载入的照片，不包含视频。状态栏分别显示当前载入、匹配总数、已选及窗口外的已选数量。

单图左右切换可跨加载批次，视频不进入单图导航；胶片栏保留当前照片与前后各 40 张摘要，按需读取缩略图。打开单图保留批选，单图评分、关键词、编辑、分享、XMP 和导出只作用当前照片。返回网格定位当前照片并保留有效批选；超出已载入范围时先载入锚点附近完整批次，向前和向后滚动可继续加载。标注后不再匹配的项目移出列表和批选；单图当前照片可留作切换锚点。

## 连续选片与撤销

| 快捷键 | 行为 |
| --- | --- |
| 0–5 | 评分；网格作用于已选照片，单图作用当前照片 |
| Shift + 0–5 | 评分并下一张；网格多选时不可用 |
| Delete | 淘汰；单图或网格单选时前进，多选只标记 |
| U | 取消淘汰 |
| 方向键 | 网格移动焦点；单图左右切换 |
| Shift + 方向键 | 网格已载入范围连续选择 |
| 空格／Esc | 打开焦点照片／逐层返回（取消裁剪、完成编辑、返回网格）；网格中清空选择 |
| Command-A | 选择当前筛选范围内的全部照片，含未载入项目 |
| Command-Z／Shift-Command-Z | 撤销／重做；调色中使用当前调色历史 |

文本框、输入法组词、滑块和弹窗保留各自按键。撤销／重做优先交给当前文本输入框，本地调色和系统照片调色均遵守这一顺序。长按 Delete 不连续淘汰。

批量标注支持评分、旗标、关键词追加／移除／替换以及相册成员。关键词接受中英文逗号或换行。替换全部关键词需确认；普通评分直接保存且可撤销。单图关键词草稿在切换或退出前保存，失败保留草稿。

每次批量命令在一个数据库事务中完成；目标消失或写入失败整批回滚。撤销仅恢复本次涉及字段，独立字段修改保留；冲突时拒绝撤销并清除失效历史。最近 50 个标注命令在当前会话内有效，清理、来源合并、相册删除及文件整理开始前清空标注历史。相册移出不删除原照片。

## 双图比较

选中两张后点「比较」，或从质量检查器点「查看这一组」。左侧参考图固定，右侧高亮候选接收评分、淘汰与关键词操作，方向键切换候选。点「设为参考图」将候选固定并进入下一候选；没有更多候选时保持当前比较并提示。

默认同步缩放和平移，平移按图像归一化中心对应，100% 按各图物理像素显示。关闭联动可独立查看细节。「适应」「100%」作用于两个画布。最多两张活动大图与一张候选预取，退出取消任务、释放图像。单侧解码失败不清空另一侧。

比较中「编辑当前照片」进入现有单图编辑流程。相似组仅作整理参考，不自动挑选最佳照片，不改变质量算法或校准门禁。

## 失败、后台任务与文件输出

缩略图失败显示原因和重试／重新授权入口；即使关闭文件名显示，失败项目仍保留名称与选择入口，右键也可重新载入。来源离线、授权失效、缺失和解码失败不会持续显示加载动画。缓存仍按文件身份、修订及实际屏幕比例区分；同键请求合并，单个订阅取消不影响其他订阅。

状态栏把照片数量与任务进度分开，最近操作菜单保留本次会话的结果。分析期间可浏览和标注；文件整理、调色、分享及 Codex 操作保留互斥。维护操作收在「整理」菜单，存在未完成归档时显示恢复入口。

XMP 经预检和确认后只创建新文件。已有文件、符号链接和多照片映射同一 XMP 均跳过。取消保留已完成文件；数据库标注、照片身份或来源变化会拒绝旧清单。没有整份替换或字段合并入口。

## 验证

统一入口：`zsh Scripts/build.sh check`。专项覆盖 XMP 竞争、批量字段撤销、十万项游标遍历、字面搜索及缩略图取消。构建后的 `JingXuChecks --workflow-ui-fixtures` 可在仓库外生成 1,006 张合成照片的独立图库（含一张损坏样本及一个相似组），用于观察窗口淘汰与反向载入。用 `JINGXU_UI_TEST_ROOT` 指向该目录才能隔离整个应用；Sandbox 包必须使用独立应用标识，并将图库置于其容器授权范围。

原生键盘焦点、输入法、多屏、RAW、快速切图及分享需在隔离应用中实测，Core 检查不替代这些验收。实际结果记录在 OptimizationValidation.md。
