# 镜序 v0.2.2

macOS 14+ · Apple Silicon · build 9

- 修复单图预览访问授权过早释放：授权保持到切走或关闭预览。
- RAW 从内存数据解码并生成独立 sRGB RGBA8 像素，避免后续绘制重新访问已失去授权的源文件。
- 原图串行解码，减少快速 A → B → A 切图时的并发内存占用。
- 保留底部胶片栏、方向键切图、评分和旗标功能。

Debug / Release 构建与 18 项回归通过，包括重复切图像素一致性、授权对象生命周期和临时源文件移走后的显示。真实 RAW 来源目前无法在原路径访问，修复后的沙盒实机复验尚未完成，不宣称花屏已彻底消失。

使用临时签名，未完成 Developer ID 签名与 Apple 公证；保留 Pre-release 标识，下载后可能被 Gatekeeper 阻止，请勿关闭系统安全保护。

安装前退出全部旧版并备份图库数据容器；将 DMG 内镜序.app 拖入应用程序替换，停用其他旧副本。Bundle ID、沙盒权限、图库路径不变。本次修复不新增数据库迁移；从旧版本首次升级仍会执行既有迁移保护。不要删除数据容器。降级需使用对应版本数据库备份，恢复会回退备份后的标注。

不包含用户照片、图库、人工标注或凭据。原图不被修改。
