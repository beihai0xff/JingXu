# 镜序 0.7.0

构建 31，macOS 14+、Apple Silicon。

## 直接拖动直方图调色

- 成片直方图从左至右提供黑色、阴影、曝光、高光、白色五个等宽交互区，悬停显示区域与当前数值。
- 左右拖动直接调整对应参数，与调色滑块、照片预览和成片直方图同步。按下位置锁定参数，跨区拖动不会切换。
- 每次有效拖动合并为一步撤销，沿用自动保存、重做和原图对比；切图、离开调色及操作中断时结束手势，已退出会话不接受迟到修改。
- 区域仅用于选择参数，不代表精确的算法作用范围。复用现有调色和导出流程，不修改原照片，不改变数据库格式。

## 验证与安装边界

本版本沿用 ad-hoc 签名、未经 Apple 公证的测试预发布通道。安装前结束后台任务、退出旧应用并备份图库，保留系统安全保护。发布流水线对发布提交执行 Debug／Release 构建、完整回归、应用签名验证、DMG 完整性及 GitHub 资产摘要校验。

本次功能在升级版本号前已通过本地统一 Debug／Release 构建、54 项回归和 29 项发布脚本检查。新增检查覆盖分区边界、方向与灵敏度、范围限制、无变化手势、一步撤销／重做、保存重开、保存失败保留草稿及退出后的迟到事件。公开 Nikon RAW 样本及 JPEG 副本已通过真实解码、JPEG／16 位 TIFF 导出和原片 SHA-256 不变检查。

同一功能已用版本号升级前的本地签名程序备份后替换安装，安装程序一致性及签名校验通过，并在独立测试图库中读取 JPEG／RAW、进入 JPEG 单图。打开调色时原生界面控制连接中断，重连仍失败，实际拖动、悬停、滑块同步、快速切图和窗口中断尚未完成界面验收。

本地测试 DMG 生成曾遇系统“资源忙”，未将该次操作标为打包成功。GitHub 发布产物仍须由流水线独立生成并校验。该版本的下载后 Gatekeeper 首次安装及实际 Homebrew 升级尚未验收。
