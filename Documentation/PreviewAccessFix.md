# 原图预览访问生命周期修复

## 变更

- `PreviewAccessLease` 平衡安全作用域开始／结束调用；成功结果由单图状态持有，切走、关闭或重试时释放。失败、取消及过期加载结果不留下额外持有者。
- ImageIO 从非映射的内存数据创建解码源，防止返回的解码资源再次通过文件 URL 打开原文件。
- 在返回之前完成方向处理与 sRGB RGBA8 像素物化，CGImage 只引用独立的内存数据，不依赖文件、ImageIO 源或 Core Image 上下文。
- 串行执行原图解码，进入队列和昂贵阶段之间检查取消；无法强制中止正在执行的系统解码调用，但取消任务不再发布结果。

## 验证与边界

自动化覆盖 JPEG A → B → A 重复加载、定向预览、固定像素格式、预览持有授权对象、释放预览时释放授权对象，以及删除临时源文件后像素不变。真实用户照片不用于删除测试。

这些测试不能替代真实沙盒的 security-scoped bookmark 验证。实机验收需在签有沙盒权限的应用中，使用系统选择器授权真实 RAW 来源，连续执行 A → B → A、快速切图、100% 与退出重进，核对图像并确认没有新的 ImageIO 文件读取权限错误。

本次不迁移数据库、不修改来源文件、不替换已安装应用、不发布现有 GitHub 草稿。真实 RAW 样本在先前位置不可用，实机验收待重新取得有效来源后执行。
