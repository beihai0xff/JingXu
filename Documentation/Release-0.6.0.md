# 镜序 0.6.0

构建 27，macOS 14+、Apple Silicon。

## 单张自动构图与手动裁剪

- 单图工具栏新增「构图」。在本机定位人物、人脸和显著主体，为当前照片提供一个保守的裁剪建议；不会识别人物身份或上传照片。已有裁剪默认保持当前取景，点击「重新推荐」后才重新分析。
- 支持原图比例、自由、1:1、3:2、4:3、16:9 及横竖切换。拖动画框移动取景、拖动四角调整大小，显示九宫格、框外遮罩和成片像素尺寸。
- 点击「应用」后保存到图库，作为一次可撤销编辑；「取消」丢弃构图草稿，「重置裁剪」保留调色。原文件始终不变。
- 推荐优先保留检测到的主体与留白。主体保护边距超出原图、没有可用主体，或收紧幅度很小时，建议保留原构图；指定比例无法容纳主体时提示手动调整。不保证保护未检测到的人物和肢体，请检查最终取景。

## 编辑与输出一致性

- 裁剪接入现有调色记录、文件身份与修订校验，不新增图库迁移。预览、网格和胶片栏缩略图、比较、成片直方图、分享调色成片及导出使用同一裁剪结果。
- JPEG、PNG 和 16 位 TIFF 按裁剪后的原生像素尺寸导出。仅裁剪的照片也显示为「已编辑」；照片信息中的原片尺寸保持原义。
- 调色预设、复制参数及 MCP 调色参数修改保留目标照片裁剪；撤销／重做涵盖完整编辑历史，「恢复原图」同时清除调色与裁剪。
- 切图或关闭时丢弃未应用构图；过期推荐不能覆盖手动草稿，文件替换或修订变化后禁止应用。保存失败保留编辑并可重试。

本版不包含批量构图、新增 MCP 构图工具、自动拉直、透视校正或生成式补图。

## 安装与验证边界

本版本沿用 ad-hoc 签名、未经 Apple 公证的测试预发布通道。安装前结束后台任务、退出旧应用并备份图库，保留系统安全保护。发布流水线执行本提交的构建回归、应用签名验证、DMG 完整性和 GitHub 资产摘要校验。

本次功能实现已在本机通过 Debug／Release 构建、54 组 JingXuChecks 和 29 项发布脚本检查。构图检查覆盖 EXIF 八种方向、裁剪几何、主体保护、输出一致性、取消、撤销重做、保存失败、文件替换和过期推荐。

8 个公开样本完成真实 Vision 分析及 JPEG／PNG／16 位 TIFF 裁剪导出，包含 Sony A700 ARW；导出尺寸、PNG 像素及原片 SHA-256 不变检查通过。样本用于开发回归和 Codex 目视复核，不是独立验证集或摄影师人工验收。首版推荐偏保守，最终样本中 1 张提供裁剪建议，7 张保留原构图。

Mac 锁屏阻止了本次原生交互验收。构图拖动、键盘焦点、窗口缩放、100% 显示和 Sandbox 目录授权仍需实机检查。真实图库覆盖升级、跨设备 Gatekeeper 安装和 Homebrew 升级未验收；自动化检查不能替代这些结果。未替换本机已安装应用。

操作规则及验证记录见[调色与构图说明](https://github.com/beihai0xff/JingXu/blob/v0.6.0/Documentation/ColorEditing.md)。
