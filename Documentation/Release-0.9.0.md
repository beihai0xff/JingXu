# 镜序 0.9.0

构建 34，macOS 14+、Apple Silicon。

## 浏览、选片和编辑更集中

- 图库采用侧栏与照片网格两栏布局，搜索、筛选和视图选项集中在顶部；选中照片后再显示评分、比较、相册和导出操作。
- 照片按 200 项连续载入，滚动即可继续浏览。全选覆盖当前筛选范围内尚未载入的照片，批量整理使用完整选择。
- 单图集中放置切图、编辑、导出与分享；Esc 依次取消裁剪、完成编辑、返回网格，返回后保留选择。
- 调整、裁剪和预设合并到编辑侧栏。预设先预览再应用，未应用的预览不会写入图库，也不能直接导出或分享。
- 导出在同一窗口选择格式与目录、核对固定文件清单，完成后分别显示成功、跳过和失败；同名文件继续跳过。
- 系统照片使用相同的浏览与编辑结构，区分本机调色草稿和明确保存到系统照片。保存成功不代表 iCloud 已完成同步。
- README 提供直接下载、安装、四步上手、界面截图和常见问题；同步清理旧分页及未使用代码。

日常浏览、评分与调色保留原片。归档、移动和清理仍使用原有清单确认、备份与恢复机制；本地文件删除只走废纸篓。

## 验证与安装边界

本版本沿用 ad-hoc 签名、未经 Apple 公证的测试预发布通道。安装前结束后台任务、退出旧应用并备份图库，保留系统安全保护。

2026-10-16 晚间已重新通过全部 arm64 Debug／Release 构建、55 项应用回归、29 项发布脚本检查和差异格式检查。隔离界面已复查完整选择、连续载入、评分撤销、胶片切图，以及 Release 版曝光保存、预设预览限制、裁剪与 JPEG 导出；导出文件实际尺寸为 80 × 80 像素。

本轮未完成关键词保存和系统照片界面的额外复查：照片详情读取时界面自动化服务发生故障，随后设备锁定。这些项目不计为已验收；本版本继续作为测试预发布版提供。最终提交的构建回归、签名、DMG 完整性及发布资产摘要由现有 GitHub Actions 流水线检查。

真实 PhotoKit 授权、真实 RAW 相机组合及 iCloud 跨设备同步需要专用账户和图库，不能以合成素材或假服务检查代替。Gatekeeper 首次安装、覆盖升级和实际 Homebrew 升级不在本次隔离验证范围内。

详见 [界面改动与验收记录](https://github.com/beihai0xff/JingXu/blob/v0.9.0/Documentation/InterfaceRefactor.md)、[调色与导出](https://github.com/beihai0xff/JingXu/blob/v0.9.0/Documentation/ColorEditing.md) 和 [系统照片](https://github.com/beihai0xff/JingXu/blob/v0.9.0/Documentation/SystemPhotos.md)。
