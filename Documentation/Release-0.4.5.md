# 镜序 0.4.5

构建 24，macOS 14+、Apple Silicon。

## 修复与优化

- 评分、旗标和关键词按字段原子保存，避免快速交错操作覆盖其他标注。多选时仍只修改焦点照片；保存失败不前进到下一张。
- 扫描显示部分失败及原因，分别统计目录、文件和元数据错误，保留前 30 条详情。不可读目录不再静默跳过；数据库写入失败停止扫描，已提交记录保留。取消或失败后刷新图库；解析失败的文件在重扫时重试。
- 新增全图库与按来源浏览排序索引，精简完整匹配计数的不必要关联；同日期同名照片使用稳定顺序。保留目录精确匹配、完整操作范围及 2,000 项显示上限。
- PR 自动执行统一构建回归；发布仍仅由新版本标签触发。
- 不更改数据库格式、图库位置或 Sandbox 权限；保留已有旧图库备份升级和恢复机制，不自动扫描或重算旧照片。

## 安装与验证边界

当前采用临时签名，未经 Apple 公证，以测试预发布版提供。安装前退出旧应用并备份图库，不关闭系统安全保护。

本机统一入口的 Debug／Release 构建、40 组应用检查和 29 项发布脚本测试通过，覆盖并发标注、失败回滚、目录权限、取消、数据库批次失败、索引补齐及旧库备份升级。10 万条合成记录、Release 构建、预热后 5 次中位数：首批列表加完整计数，全图库约 12 ms、来源约 14 ms、搜索约 63 ms；这是数据库调用测量，不是 UI 帧率。

独立图库和独立应用标识的开发界面已验证来源扫描、分析结束后查看部分失败详情、关闭报告后切换侧栏。随后原生界面自动化连接中断，标注鼠标操作、真实键盘连续输入、快速切图及多选焦点交互未完成本次 UI 验收；相关数据库并发和选择状态已有自动检查，不等同于系统交互验收。真实 RAW、跨设备 Gatekeeper 安装、真实图库覆盖升级及 Homebrew 升级未验收。发布流水线继续执行应用签名、镜像完整性和 GitHub 资产摘要校验。
