# 镜序 0.4.2

构建 21，macOS 14+、Apple Silicon。增加来源目录树及按文件夹浏览。

- 来源下逐层展示已索引媒体所在目录，保留离线目录与索引计数。
- 默认包含子目录，也可只看当前层；记住开关，切换目录保留筛选并清空选择。
- 淘汰清理、失效索引清理及当前范围重算使用完整目录条件，不受 2,000 项网格上限影响。
- 目录切换先保存调色，异步查询隔离过期响应；移动、归档、撤销或清理后更新目录树。
- 无数据库格式变更，不自动移动照片、不自动清理缺失文件，不为子目录新建来源。

安装前结束后台任务并退出旧应用、备份图库，再替换「应用程序」中的镜序。应用标识与图库路径不变。本版使用临时签名，未经 Apple 公证，作为预发布版提供；不要关闭系统安全保护。

功能实现已通过统一入口的 Debug／Release 构建、32 项应用回归、29 项发布脚本校验及本机临时签名打包。已完成本机覆盖安装和启动检查，安装前后图库逻辑内容、删除及归档日志一致；未操作原照片。GitHub 安装包由标签流水线在合入提交上重新构建、校验并生成，Homebrew 在发布成功后更新。

部分实际界面交互已在独立测试图库检查；展开箭头鼠标操作、调色保存失败时阻止切换、高频连续切换、AI 范围变更端到端交互、跨设备 Gatekeeper 安装和完整 XCUITest 尚未验收。详情见 [目录浏览说明](https://github.com/beihai0xff/JingXu/blob/v0.4.2/Documentation/FolderBrowsing.md)。
