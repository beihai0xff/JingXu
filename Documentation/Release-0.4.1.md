# 镜序 0.4.1

构建 20，macOS 14+、Apple Silicon。增加完整 v4 旧图库（包括 0.2.6）的受保护单向升级，可继续使用 0.4.0 的调色及 AI 连接功能；AI 连接默认关闭。

- 只读检查旧库结构、完整性及外键；未知或不完整格式仍拒绝打开。
- 排他锁、含 WAL 的在线备份、删除与归档日志及摘要清单；备份失败停止。
- 事务补充调色表和格式标识，不重新索引，不改变原记录及照片。
- 恢复时一并保全及校验归档日志，支持持久恢复意图重试。

安装前结束任务、退出旧应用并备份。未解决的文件操作须依日志安全处理；数据库备份不能代替文件撤销。不能仅换回旧应用作为安全降级。详见 [迁移说明](LegacyCatalogUpgrade.md)。

通过 GitHub Actions 的 adhoc 通道发布临时签名、未公证安装包，不降低系统安全保护。统一构建入口的 Debug／Release 构建、29 项发布脚本测试和 30 组应用回归已通过。本机先验证旧图库副本，再备份并安装；全部旧表逐字段一致，删除及归档日志记录一致，数据库完整性与外键检查通过，退出重开正常。未修改原照片。

跨设备、磁盘故障、断电、Homebrew 跨版本安装及完整 XCUITest 未验收；不能以本机验证替代这些场景。新旧版不能并行操作同一图库，切勿仅替换旧程序来降级数据。
