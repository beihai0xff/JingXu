# 镜序 v0.2.3

macOS 14+ · Apple Silicon · 构建 11

## 更新

- 修复 Sony ARW 单图显示“文件格式不正确”：内存解码时保留 RAW 类型提示，不回退到延迟文件读取。
- 新增“清理失效索引…”：按当前来源、相册、搜索与筛选范围检查，不受 2,000 项限制；确认后备份、再次复核并清理数据库记录。
- 离线、权限异常、目录身份变化和已经恢复的文件保留。只清理索引及关联数据，不操作原文件。数据库错误或取消回滚整批操作。

## 验证与限制

Debug / Release 构建及 Release 19 项回归通过。两张本机真实 ARW 样本通过定向显示、缩放及重复读取验证，原文件 SHA-256 未变。样本及私有输出不上传。

本地构建 10 安装前后，610 项资源及来源、评分、旗标、标签、相册、分析、导入记录对比一致。发布构建 11 仅更新版本信息，尚未完成下载 DMG 的 Gatekeeper 和完整沙盒 UI 人工验收。Debug 完整回归曾遇到系统书签授权错误，未宣称通过。

## 安装与回退

本版本为临时签名、未经过 Apple 公证的预发布版本，文件名不带 test。不要关闭系统安全保护。先退出旧程序并备份图库，再打开 DMG，将“镜序.app”拖入“应用程序”替换；停用其他目录里的旧副本。

Bundle ID、沙盒权限和图库路径保持不变。此版本不新增数据库迁移，不自动清理索引。签名变化可能要求重新授权来源，不要删除图库来处理授权错误。

清理索引后评分、标签等不会自动恢复；回退数据须退出程序后恢复对应完整数据库备份。不要混用不同版本程序和不匹配的数据备份。

下载提供 DMG 及 SHA-256 校验文件，不覆盖已有版本资产。
